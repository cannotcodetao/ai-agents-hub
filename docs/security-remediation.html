⚠️ 执行前必读（避免把自己锁在服务器外）：
  1. 开防火墙 / 改 SSH 端口前，必须先把「新 SSH 端口、面板新端口、80、443」加入放行列表，否则开启后无法连接。
  2. 改 sudoers（#14）前，先确认存在一个「需要密码」的 sudo 用户；云厂商的 90-cloud-init-users 是初始化创建的，删 NOPASSWD 前留好后路，否则可能失去 sudo 权限。
  3. 改 SSH 配置（#9/#10/#13）后，务必开一个新终端测试能登入，再断开旧连接；重启 sshd 不会踢掉当前会话。
  4. 移除 SUID/SGID（#1）后，非 root 将无法 mount 等；确保你已有 root SSH 再操作。

执行顺序建议（降低锁死 / 误操作风险）

  1. SSH 加固先测通：#9 空闲超时、#10 登录超时、#13 Protocol 2 —— 改完 systemctl restart sshd，新终端验证可登录再继续。
  2. 面板端口：#4 改面板端口（安全组先放行新端口）。
  3. 开防火墙：#2 系统防火墙（已放行的端口见上方警示①）。
  4. 账号提权保护：#14 sudoers NOPASSWD（先留密码 sudo 用户）、#18 wheel su（先确认自己在 wheel 组）。
  5. 特权文件：#1 SUID/SGID（确认有 root 途径后）。
  6. 密码策略：#6 密码复用、#11 pwquality、#12 PASS_MIN_DAYS。
  7. 服务清理：#3 MySQL 3306（确认不用再处理）、#7 PHP display_errors、#15 TCP Wrappers（可选）、#16 卸载 telnet。
  8. 会话/超时：#17 命令行 TMOUT、#8 禁 Ping（按需）。
  9. 网络防护：#19 TCP SYN cookie。
  10. 监控告警：#5 面板登录告警。
